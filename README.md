## ⚡ About Me

```
┌─────────────────────────────────────────────────────────────────────────────────────────────┐
│  "Engineering is the art of transforming raw physical laws into intelligent, deployable    │
│   products — bridging custom PCB silicon, deterministic firmware, and edge machine learning." │
└─────────────────────────────────────────────────────────────────────────────────────────────┘
```

I am an **Electronics & Telecommunication Engineer** (B.Tech, BIT Durg) specializing in the end-to-end design and manufacturing of **intelligent hardware products**. Rather than treating hardware, firmware, and software as disconnected silos, I engineer complete systems from initial schematic capture to field-deployed AI models.

### 🔬 Engineering Integration Focus:
- 🔌 **Electronics & PCB Design:** Designing multi-layer boards, analog front-ends (AFE), signal conditioning circuits, and power regulation using KiCad and Proteus.
- ⚡ **Embedded Systems & Firmware:** Architecting low-latency, real-time code in Embedded C/C++ for microcontrollers (ESP32, RP2040, STM32) with UART, SPI, I2C, and CAN bus protocols.
- 🧠 **Artificial Intelligence & Edge ML:** Training and deploying lightweight machine learning models (SVM, Random Forest, CNNs) directly on resource-constrained microcontrollers.
- 🔋 **Power Systems & Clean Energy:** Industrial hands-on experience in lithium-ion battery pack assembly, Battery Management Systems (BMS), Electric Vehicles (EV), and SCADA grid monitoring.
- 📐 **Technical Documentation & Product Strategy:** Producing publication-grade technical papers, hardware architectural diagrams, and user-centered design documentation.

> **High-Speed 10MHz Signal Synthesizer** | *RP2040, PIO State Machines, R-2R DAC, LCD UI*

  <tr>

      </p>
      <p align="center">
        <a href="https://github.com/Immanueal1"><img src="https://img.shields.io/badge/GitHub-View_Repository-181717?style=for-the-badge&logo=github&logoColor=white" alt="GitHub Repository" /></a>
        <a href="#"><img src="https://img.shields.io/badge/Schematic-View_KiCad-314E87?style=for-the-badge&logo=kicad&logoColor=white" alt="Schematic" /></a>
      </p>
    </td>
    <td width="50%" valign="top">
      <h4>📋 Project Case Study Overview</h4>
      <ul>
        <li><b>Problem Statement:</b> Commercial benchtop function generators are bulky and expensive for field electronics diagnostics and educational workbenches.</li>
        <li><b>Engineered Solution:</b> Exploited the unique dual-core RP2040 Programmable I/O (PIO) architecture and Direct Memory Access (DMA) to stream arbitrary digital waveform data to a precision R-2R DAC ladder.</li>
        <li><b>Key Tech Stack:</b> RP2040 C/C++ SDK, Assembly (PIO State Machine), R-2R DAC Network, LCD Display, Rotary Encoder.</li>
        <li><b>Results & Performance:</b> Synthesizes Sine, Square, Triangle, Sawtooth, and arbitrary waveforms at output frequencies up to <b>10 MHz</b> with low phase jitter.</li>
      </ul>
    </td>
  </tr>
</table>

<details>
<summary>🔍 <b>Architecture, Hardware Design & Technical Deep-Dive (Click to expand)</b></summary>
<br/>

```
[ User Input (Encoder) ] ──> [ RP2040 Core 0 (UI & Waveform LUT) ]
                                         │ (DMA Buffer Transfer)
                                         ▼
                             [ RP2040 PIO Hardware Engine ] ──> [ Precision R-2R DAC ] ──> [ BNC Analog Output ]
```

- **Engineering Challenges:** Eliminating CPU cycles during signal generation by offloading 100% of parallel data bus transfers to RP2040 DMA channels and PIO assembly state machines.
- **Future Improvements:** Adding dual-channel synchronized phase control and active op-amp reconstruction filtering.

</details>
